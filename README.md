# Marienella Lustria — Portfolio (Next.js)

```bash
npm install
npm run dev      # http://localhost:3000
```

Deploy: push to GitHub and import at vercel.com/new (Next.js is auto-detected), or run `npx vercel`.

## Editing content
- `data/site.js` — name, email, nav, social links (replace the `#` URLs), stats, details
- `data/projects.js` — projects (images live in `public/images/`)
- `data/skills.js` — skill groups
